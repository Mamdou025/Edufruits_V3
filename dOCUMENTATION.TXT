# 🚀 EduFruit Setup Scripts

Complete automated setup system for EduFruit V3 fruit classification project.

## 📋 Quick Start

### Option 1: One-Command Setup (Recommended)
```bash
python setup_edufruit.py
```
This master script will guide you through the entire process!

### Option 2: Step-by-Step Setup
```bash
# Step 1: Download dataset
python 1_download_dataset.py

# Step 2: Setup environment  
python 2_setup_environment.py

# Step 3: Train model
python 3_train_model.py

# Step 4: Run web app
python 4_run_streamlit.py
```

## 📄 Script Details

### `setup_edufruit.py` - Master Setup Script
**Purpose:** Orchestrates the entire setup process  
**Time:** 20 minutes - 2.5 hours  
**What it does:**
- Guides you through setup mode selection
- Runs all scripts in sequence
- Provides progress tracking and error handling
- Shows final summary and next steps

---

### `1_download_dataset.py` - Dataset Downloader
**Purpose:** Downloads and extracts required fruit data  
**Time:** 5-15 minutes  
**Size:** ~200MB download  

**What it does:**
- Downloads Fruits-360 dataset from Kaggle
- Extracts only the 18 fruit varieties needed for EduFruit
- Saves ~400MB by excluding unused varieties
- Organizes data in `data/raw/fruits-360/`

**Prerequisites:**
- Kaggle API configured (script provides setup instructions)

---

### `2_setup_environment.py` - Environment Setup
**Purpose:** Creates Python environment and installs dependencies  
**Time:** 3-10 minutes  
**Size:** ~500MB packages  

**What it does:**
- Creates `edufruit_env` virtual environment
- Upgrades pip to latest version
- Installs all required packages (TensorFlow, Streamlit, etc.)
- Verifies installation with import tests
- Creates activation instructions

**Prerequisites:**
- Python 3.8+ installed
- pip available

---

### `3_train_model.py` - Model Training
**Purpose:** Trains CNN model for fruit classification  
**Time:** 10 minutes - 2 hours (depends on epochs)  
**Size:** ~50MB model file  

**What it does:**
- Checks data and environment prerequisites
- Offers training mode selection (5-50 epochs)
- Runs the main training script (`train_edufruit.py`)
- Finds and reports trained model location
- Optionally runs model evaluation
- Creates training summary

**Prerequisites:**
- Dataset downloaded (step 1)
- Environment setup (step 2)

**Training Modes:**
- **Quick Test:** 5 epochs, ~10 minutes, ~90% accuracy
- **Development:** 15 epochs, ~30 minutes, ~95% accuracy  
- **Production:** 30 epochs, ~1 hour, ~98% accuracy
- **Full Training:** 50 epochs, ~2 hours, ~99%+ accuracy

---

### `4_run_streamlit.py` - Web App Runner
**Purpose:** Starts the Streamlit web interface  
**Time:** Instant startup  

**What it does:**
- Finds Streamlit application files automatically
- Checks prerequisites (model, data, Streamlit)
- Configures Streamlit settings
- Finds available port (default 8501)
- Starts web application and opens browser
- Provides usage instructions

**Prerequisites:**
- Environment setup (step 2)
- Model trained (step 3)

## 🔧 Troubleshooting

### Common Issues:

#### "Kaggle API not configured"
**Solution:**
1. Go to https://www.kaggle.com/account
2. Click "Create New API Token"
3. Download `kaggle.json`
4. Place it in your user directory:
   - **Windows:** `C:\Users\{username}\.kaggle\kaggle.json`
   - **Linux/Mac:** `~/.kaggle/kaggle.json`

#### "Virtual environment creation failed"
**Solution:**
```bash
# Install venv if missing
pip install virtualenv

# Or use conda instead
conda create -n edufruit_env python=3.9
conda activate edufruit_env
```

#### "Package installation failed"
**Solutions:**
```bash
# Upgrade pip first
pip install --upgrade pip

# Install packages individually
pip install tensorflow
pip install streamlit
# etc.

# Or use conda
conda install tensorflow streamlit
```

#### "Model training fails"
**Check:**
- Enough disk space (>1GB free)
- Enough RAM (>4GB available)
- Dataset was downloaded correctly
- All packages installed

#### "Streamlit app won't start"
**Check:**
- Virtual environment is activated
- Streamlit is installed: `pip install streamlit`
- Model file exists in `models/` directory
- Port 8501 is available

### Getting Help:

1. **Check error messages** - scripts provide detailed error info
2. **Run individual steps** - isolate the problematic step
3. **Verify prerequisites** - ensure each step's requirements are met
4. **Check file paths** - ensure you're in the project root directory
